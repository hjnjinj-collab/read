# 仿真翻页动画与光影设计

## 1. 文档目的

本文档记录 `legado_flutter` 当前仿真卷曲翻页动画的设计、几何模型、绘制顺序以及光影处理方式。

本文档的目标是让后续维护者能够在不破坏现有效果的前提下继续调整动画，并明确区分以下两类阴影：

1. 卷起页自身的边缘光影；
2. 卷起页投射到其他页面平面的投影。

主要实现文件：

- `lib/features/reader/presentation/widgets/page_turn/curl_painter.dart`
- `lib/features/reader/presentation/widgets/page_turn/page_turn_controller.dart`
- `lib/features/reader/presentation/widgets/page_turn/page_turn_types.dart`

参考实现：

- `legado-with-MD3/app/src/main/java/io/legado/app/ui/book/read/page/delegate/SimulationPageDelegate.kt`

---

## 2. 整体设计

仿真翻页使用“当前页 + 目标页 + 当前页镜像背面”的三页绘制模型。

当用户从右下角向左拖动进行下一页翻页时：

- 当前页的部分区域保持在正面；
- 被拖动区域从当前页中剪掉；
- 目标页在被翻起区域下方显示；
- 被翻起的当前页通过镜像矩阵绘制背面；
- 页脚边缘向下方页面投射阴影；
- 所有阴影随着 `washScale` 变化，并在动画结束时自然淡出。

上一页翻页使用相同模型，但折角位于左下角，几何方向和渐变方向根据翻页方向切换。

### 2.1 绘制层级

当前绘制顺序如下：

```text
页面底色
  ↓
当前页正面可见区域
  ↓
目标页露出区域 + 目标页投影
  ↓
卷起页背面：纸张底色 + 镜像内容
  ↓
卷起页脚自身边缘光影
  ↓
卷起页脚投射到上一页的阴影
  ↓
其他局部翻页阴影
```

其中，目标页投影和卷起页脚投影必须使用不同的裁剪区域，不能将二者合并，否则阴影会覆盖到卷页镜面或错误页面。

## 3. 几何模型

### 3.1 关键点

几何计算由 `calcCurlPoints` 完成，结果保存在 `CurlPoints` 中。

| 点 | 含义 |
| --- | --- |
| `touch` | 用户手指或动画插值对应的触点 T |
| `corner` | 被拖动的页面角点，下一页通常为右下角，上一页通常为左下角 |
| `ctrl1` | 第一条贝塞尔折缝的控制点，位于底边 |
| `ctrl2` | 第二条贝塞尔折缝的控制点，位于侧边 |
| `start1` | 第一条贝塞尔曲线起点 |
| `start2` | 第二条贝塞尔曲线起点 |
| `end1` | 第一条贝塞尔曲线与折叠边界的交点 |
| `end2` | 第二条贝塞尔曲线与折叠边界的交点 |
| `vertex1` | 第一条贝塞尔曲线顶点近似 |
| `vertex2` | 第二条贝塞尔曲线顶点近似 |
| `dis` | 触点到角点的距离 |

### 3.2 两条卷曲曲线

卷页的两条主要曲线是二次贝塞尔曲线：

```text
curve1: start1 → ctrl1 → end1
curve2: start2 → ctrl2 → end2
```

两条曲线的控制点分别固定在页面的底边和侧边，因此能够形成从页脚向触点收拢的卷曲形状。

贝塞尔顶点使用以下近似公式：

```text
vertex = (start + 2 × control + end) / 4
```

### 3.3 折叠区域路径

`path0` 表示被卷起的页面区域：

```text
start1
  → curve1
  → end1
  → touch
  → end2
  → curve2
  → start2
  → corner
```

`path1` 表示背面或卷曲折叠区域：

```text
vertex1 → vertex2 → end2 → touch → end1
```

背面区域为：

```text
backFace = path0 ∩ path1
```

### 3.4 镜像矩阵

镜像矩阵用于将当前页内容翻转到卷页背面。

镜像轴是经过 `ctrl1` 的折痕轴，而不是简单使用 `start1 → start2`。这样可以保证：

- `ctrl1` 位于镜像轴上；
- 角点 `corner` 镜像后落到 `touch`；
- 正面内容和背面镜像内容在折缝附近连续；
- 不会因为错误的轴枢轴产生页面偏移。

该矩阵通过 `foldMirrorMatrix` 计算，并在绘制镜像内容时临时作用于 Canvas。

## 4. 页面裁剪区域

### 4.1 当前页正面

当前页正面可见区域：

```text
frontVisible = pageRect - path0
```

当前页内容只允许绘制在这个区域中。

### 4.2 目标页露出区域

目标页使用一个由以下点组成的多边形：

```text
start1 → vertex1 → vertex2 → start2 → corner
```

目标页露出区域为该多边形与 `path0` 的交集：

```text
revealArea = pentagon ∩ path0
```

目标页内容和目标页投影都必须限制在这个区域中。

### 4.3 卷页背面

卷页背面只允许绘制在：

```text
backFace = path0 ∩ path1
```

背面绘制顺序为：

1. 绘制不透明的纸张背面底色；
2. 绘制当前页镜像内容；
3. 绘制卷页自身边缘光影。

### 4.4 阴影职责隔离

当前实现中，底页投影使用从 `revealArea` 中排除 `backFace` 后的区域：

```text
revealShadowArea = revealArea - backFace
```

这样可以避免目标页投影叠加到卷页镜面上。

卷起页脚投影则使用 `frontVisible`，因为它属于当前可见底页平面，而不是卷页镜面。

## 5. 光影设计

### 5.1 光影职责

当前光影分为三类：

| 光影 | 所在平面 | 主要作用 |
| --- | --- | --- |
| 目标页投影 | 目标页露出平面 | 表现卷曲区域对下一页的遮挡 |
| 页脚自身边缘光影 | 卷起页内部 | 表现被提起纸张的边缘厚度和受光 |
| 页脚投影 | 当前页正面平面 | 表现卷起页脚遮挡光线后投射的阴影 |

三类光影不能共用同一个绘制区域。

### 5.2 目标页投影

目标页投影参考 MD3 的 `drawNextPageAreaAndShadow`，特点如下：

- 使用旋转线性渐变矩形；
- 以 `start1` 为旋转锚点；
- 矩形宽度与 `dis / 4` 相关；
- 投影限制在 `revealShadowArea`；
- 靠近折痕的一侧颜色较深；
- 远离折痕的一侧逐渐透明；
- `next` 和 `prev` 方向使用相反的渐变方向。

当前使用的主色为冷灰蓝色：

```text
#39444F
```

该颜色比纯黑更接近参考图的投影效果，也能与米白色页面形成自然对比。

渐变结构为：

```text
深色核心 → 深色过渡 → 透明
```

投影的深色区域不能过早结束。参考图中的深色部分在折痕附近保持一定宽度，然后才逐渐羽化。

### 5.3 卷起页脚自身边缘光影

卷起页脚边缘使用以下路径：

```text
mirrorEdge = end1 → touch → end2
```

该路径限制在 `path0` 内，只负责表现纸张自身边缘，不负责给底页投影。

设计原则：

- 边缘需要可见，不能完全消失；
- 使用窄核心，不使用大范围雾状羽化；
- 颜色与底页投影保持一致或接近；
- 适度使用圆角线端，避免曲线端点出现断裂；
- 不应覆盖镜像内容形成大面积纹理。

当前边缘光影采用窄渐变带：

```text
窄暗部 → 轻微过渡
```

不建议重新加入宽度很大的远端独立描边，因为这会造成“页脚两端被挑起”的视觉错觉。

### 5.4 页脚投射到当前页的阴影

页脚投影使用完整边界路径：

```text
start1
  → curve1
  → end1
  → touch
  → end2
  → curve2
  → start2
```

它绘制在 `frontVisible` 内，表示被卷起页脚投射到当前页平面上的阴影。

投影使用多层平移渐变：

```text
靠近页脚：较深
中间区域：连续过渡
远离页脚：逐渐透明
```

页脚投影的方向沿 `corner → touch` 方向计算。该方向表示卷页从角点被提起后，阴影向页面内部展开的方向。

注意：

- 页脚投影不能裁剪到 `path0`，否则只能看到卷页内部的边缘暗线；
- 页脚投影不能绘制到 `backFace`，否则会污染镜像面；
- 投影路径必须包含两段贝塞尔曲线，否则只会覆盖页脚中间一段。

### 5.5 镜像面后续光影

当前阶段只保留卷起页脚的边缘光影，不对镜像内容区域整体添加纹理。

后续如果要增加镜像面的光影，应遵守：

- 只在 `backFace` 内绘制；
- 光影从卷页边缘向镜面内部扩散；
- 不修改镜像文字和内容本身；
- 不复用底页投影；
- 不使用沿整条边缘的厚重黑色描边。

## 6. 参考 MD3 实现的对应关系

| MD3 方法 | Flutter 对应逻辑 |
| --- | --- |
| `drawCurrentPageArea` | `frontVisible` 中绘制 `foldingPage` |
| `drawNextPageAreaAndShadow` | `revealArea` 中绘制 `revealPage` 和 `_drawMd3ShadowRect` |
| `drawCurrentPageShadow` | `_drawMd3FrontShadow` |
| `drawCurrentBackArea` | `backFace` 中绘制纸背和镜像内容 |
| `mBackShadowDrawable` | 目标页投影的旋转线性渐变矩形 |
| `mFrontShadowDrawable` | 当前页局部 front shadow |
| `mFolderShadowDrawable` | 背面 folder shadow，当前阶段不绘制，以避免污染镜面 |

MD3 阴影参数的核心参考值：

```text
目标页投影宽度：dis / 4
front shadow 宽度：约 25px
背面 folder shadow 宽度：f3 = min(f1, f2)
最大渐变矩形长度：页面对角线或其 1.5 倍
```

Flutter 使用弧度制 `Canvas.rotate`，因此 Android 的角度值需要通过 `math.pi / 180` 转换，或直接使用 `atan2` 得到弧度。

## 7. 参数调整原则

### 7.1 先调整裁剪，再调整浓度

如果阴影出现在错误页面或镜像区域，优先检查：

1. `canvas.save()` / `canvas.restore()` 是否成对；
2. `clipPath` 是否作用在正确的绘制层；
3. `revealArea`、`revealShadowArea`、`backFace`、`frontVisible` 是否混用；
4. 阴影矩形的旋转锚点是否正确。

不要通过降低 alpha 来掩盖错误的裁剪区域。

### 7.2 先调整深色区域，再调整羽化范围

如果投影过淡：

- 先提高折痕附近的 alpha；
- 延长深色保持区；
- 再调整远端透明过渡。

如果页脚像被挑起：

- 先移除远端独立描边层；
- 再收窄边缘核心；
- 最后才调整模糊半径。

### 7.3 颜色原则

推荐使用统一的冷灰蓝色系：

```text
主投影：#39444F
较浅过渡：主投影降低 alpha
纸张颜色：沿用页面自身底色
```

避免使用完全不透明的纯黑阴影。纯黑容易让投影变成贴纸式轮廓，无法形成参考图中的纸张空间感。

## 8. 已知约束和常见问题

### 8.1 不要把直线弦当作卷曲边缘

`end1 → end2` 是弦线，不是真实卷曲边缘。沿该直线绘制阴影会产生与卷页不一致的直线黑影。

真实连续边缘应经过 `touch`：

```text
end1 → touch → end2
```

如果需要覆盖完整页脚，则必须使用两段贝塞尔曲线和触点脊线组成的完整链。

### 8.2 阴影消失通常是裁剪问题

常见原因：

- 投影被画在 `frontVisible` 之外；
- 投影被 `backFace` 覆盖；
- 投影先画后又被页面内容覆盖；
- 阴影路径只位于 `path0` 内；
- 旋转矩形方向与页面方向不一致。

### 8.3 边缘过实通常是重复叠加

以下层同时存在时容易产生厚重灰边：

- 页脚自身边缘描边；
- 底页投影核心层；
- front shadow；
- 触点暗影；
- 背面 folder shadow。

调整时应先确认每一层的职责，再决定保留或移除，不要盲目继续降低或增加所有 alpha。

### 8.4 冷启动要求

修改 `CustomPainter` 后，必须完全停止应用并重新执行：

```powershell
flutter run -d windows
```

不能只依赖热重载判断最终效果。

## 9. 测试与验证

每次修改光影后至少执行：

```powershell
flutter analyze
flutter test test/curl_geometry_test.dart
git diff --check
flutter run -d windows --no-resident
```

当前几何回归测试覆盖：

- 折角计算；
- 直线交点；
- 贝塞尔顶点；
- 镜像矩阵正交性；
- 镜像矩阵行列式；
- 镜像轴不动点；
- 角点镜像到触点；
- 出界触点回拉；
- 极端几何下的有限值保护。

当前验证目标为：

1. 卷页边缘保持可见；
2. 页脚完整边界具有连续光影；
3. 下一页存在明确的冷灰色投影；
4. 投影从折痕附近向外逐渐羽化；
5. 投影不进入卷页镜面；
6. 页脚远端不会产生“被挑起”的轮廓错觉；
7. 动画结束时光影随 `washScale` 平滑归零。

## 10. 后续扩展建议

如果继续提升到参考图的完整效果，建议按以下顺序进行：

1. 保持当前下一页投影和页脚投影不变；
2. 在 `backFace` 内增加基于折缝距离的镜面明暗渐变；
3. 增加非常轻的卷页脊线高光；
4. 根据 `next` / `prev` 分别校准光照方向；
5. 增加截图回归测试，锁定典型触点和拖动距离下的渲染结果。

任何新增镜面光影都必须与底页投影分层实现，避免再次出现阴影串到卷页镜面的情况。
