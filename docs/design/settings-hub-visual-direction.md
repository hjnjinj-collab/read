# 设置根页 · 视觉方向提案（艺术向）

> 2026-09-19 ｜ 配合 `ui-next-roadmap.md` ｜ 产品约束已确认：
> - 底栏悬浮叠压 = **体系优势，不修**
> - 语言/同步/通知等 = **有意占位，不删**
> - 不因「材质与阅读同权」再堆一层 IA 布局
> - 要：去「棱角分明」；要：前沿 / 艺术感，**避免同质化 MD3 列表**

## 诊断（为何发硬，与玻璃无关）

代码 `SettingsGroup(float:true)` 意图已是「一区一卡」，但落地仍是：

| 现状 | 效果 |
|------|------|
| `frostStyle=slice` 或 FrostGroup **行间 gap** | 一组仍被切成多段 |
| 每行 `SettingsRowShell` **整圈描边** | 线框感、棱角 |
| 图标再套方框 | 双重几何 |
| 分区头过小、与行无材质绑定 | 组存在感弱 |

硬，来自 **「多段 + 描边 + 图标盒」**，不是来自 IA 本身。

## 共同约束（三案皆遵守）

- IA、路由、占位条目、悬浮底栏 **不动**
- 正文阅读仍不玻璃化；根页只动 **chrome 形态语言**
- 禁止：每行全描边、图标描边方盒、行间镂空缝（艺术方向里缝要么消失要么变成「设计物」）
- 色彩仍吃现有 seed / ambient / frost 渐变，不新造色板体系

---

## 方向 A「纸页浮雕」Paper Island

**隐喻**：设置是几张浮在纸色页底上的**连续纸岛**，不是表单控件。

| 维度 | 决策 |
|------|------|
| 组形态 | **真正一区一卡**：零行缝、连续圆角（24–28） |
| 描边 | **去掉每行描边**；组外轮廓仅极弱内侧光（顶亮底淡）或不描边只靠 frost 填充 |
| 组内分隔 | 可选 inset 发丝线（缩进对齐文字）或 **纯留白**——二选一，默认留白更净 |
| 分区头 | 字号升一档 + 组上方 **3px 圆角渐变短线**（吃 frost 双色），不再是孤立小字 |
| 图标 | 36 圆 tonal（primary 低透明），**无方框** |
| 占位项 | 保留；summary 可略降对比，仍可点 |
| 艺术点 | 页底 ambient 从组间「透出来」；组是岛，缝是水 |

**像什么**：Craft / 高端笔记 App 的安静目录 + 你们已有的霜面材质（只是终于「一张皮」）。

**不做**：分区色块大撞色、横向 Chip 导航。

---

## 方向 B「章节色带」Chapter Ribbon

**隐喻**：阅读器的设置 = **书的目录章节**，产品身份优先于系统设置样板。

| 维度 | 决策 |
|------|------|
| 组形态 | 连续大卡；组头变成 **「章节台」**：更高、左对齐大标题 |
| 色带 | 每组一条 **色相角色带**：个性化=primary 系，阅读与数据=tertiary 系，隐私与关于=secondary/outline 系；宽度细（4–6px）或组头底衬 |
| 行 | 行内更「印刷」：标题重、summary 弱、无描边、无行盒 |
| 图标 | 小、单色，或章节台上的装饰印记（可选） |
| 占位 | 章节台下自然存在，像目录里未展开的条目 |
| 艺术点 | 与「书」同构；切换主题色时章节带随 seed 变，有记忆点 |

**像什么**：杂志目录 / Apple Books 分区感，而不是 iOS 设置克隆。

**不做**：每行彩色底、拟物翻页。

---

## 方向 C「表现型色板」Expressive Blocks

**隐喻**：M3 Expressive——大色域、大圆角、强节奏，设置页有海报感。

| 维度 | 决策 |
|------|------|
| 组形态 | 每组一块 **角色容器色**（primaryContainer / tertiaryContainer / secondaryContainer，低透明 + frost） |
| 圆角 | 更大（28–32），整组一块，**零行描边零行缝** |
| 分区头 | 做成 **嵌在色板上的标签章**（类似大号 chip / 页签），不是列表外小字 |
| 图标 | 实心圆徽 + 对比色图标，略大，节奏感 |
| 占位 | 仍在色板内；可用更弱字重 |
| 艺术点 | 三组色相不同，滚动时有「色块翻页」节奏；最不容易被认成通用 MD3 |

**像什么**：前沿 Google 表现型实验 / 艺术 App 分区，冲击力最强。

**风险**：深色下三色板若过实会吵——需压透明度、让 ambient 透出。

**不做**：每行独立彩色卡、装饰插画堆砌。

## 推荐

| 若你更看重 | 选 |
|------------|----|
| 先去硬、稳、可马上落地、与现有霜面连续 | **A 纸页浮雕** |
| 阅读器身份、和后续「续读卡」叙事连贯 | **B 章节色带** |
| 明确要前沿艺术感、不怕再调一轮对比 | **C 表现型色板** |

**组合技（可选）**：A 的「真·一区一卡 + 去描边」作底，再加 B 的分区色带或 C 的章节标签——先 A 再叠艺术层，避免一次改到不可控。

## 与总路线关系
