# Liquid Glass System — 全应用布局蓝图

## Report

（交付时填写）

## [S1] Problem

壳层底栏/顶栏已接入 `liquid_glass_easy`，但设置页仍是 M3 `ListTile`+`SegmentedButton`，阅读菜单是白底 `Container`+`Divider`。三处材质语言分裂：书架像 iOS 海报，设置像 Material 设置样板，阅读菜单像桌面工具条。需要一份跨场景的玻璃布局规范，而不是再堆局部补丁。

## [S2] Design

### 视觉锚

| 维度 | 决策 |
|------|------|
| 一句话 | 「纸色内容 + 浮层液态玻璃；玻璃只属于 chrome，不盖正文」 |
| 材料 | 纸（阅读/书架底）、墨（字）、玻璃（导航/菜单/对话） |
| 禁止 | 半实色板叠 blur；正文整页 BackdropFilter；玻璃上再套第二层 Lens（Morph 除外且必须无内层 Lens） |

### Token（与 `AppGlass` / ExpandableGlassNav 对齐）

| Token | 值 | 用途 |
|-------|-----|------|
| `shellGlass` | `navGlass(strength: 0.38)` + blur(navBlur) | 底栏、阅读菜单壳 |
| `chromeGlass` | `navGlass(strength: 0.22)` + blur 6–8 | 顶栏控件、设置卡片、次级浮层 |
| `idleBorder` | `outlineVariant` @ 0.55/1.25 | 无背景模糊时的可读描边 |
| `softBorder` | white @ 0.2–0.4 / 1 | 有 blur 背景时的光边 |
| `radiusNav` | 32 | 底栏胶囊 |
| `radiusSheet` | 28 | 底部 sheet / 阅读菜单 |
| `radiusChip` | 20 | 设置内分段/色块 |
| `radiusAction` | 16 | 菜单格子按钮 |
| 间距 | 8 / 12 / 16 / 24 | 与壳层 pad 一致 |

### 场景矩阵

| 场景 | 玻璃层级 | 形态 | 用户 90% 动作 |
|------|----------|------|----------------|
| 书架/书源/设置 Tab | 壳底栏 + 顶栏 | 已实现可扩展胶囊 | 切 Tab、开书 |
| 设置页 | 无整页玻璃；**分组卡片** chromeGlass | 滚动列表 | 调主题/玻璃参数 |
| 阅读正文 | **无玻璃** | 纸/夜纯色 | 读、翻页 |
| 阅读菜单 | 底部 **attached sheet** shellGlass | 从底滑入 | 调进度/翻页/字体 |
| 阅读顶栏 | 渐变雾 tint（非 Lens） | 常显细条 | 返回、看章节 |
| 对话框（目录/搜索） | 浮层 chromeGlass | 居中或 sheet | 选章、搜词 |

### 设置 IA（两级：根目录 → 子页）

**原则**
- 根页只做「分类入口 + 当前值摘要」，**不**堆全部开关  
- 子页最多一层；再细用 sheet/dialog，不出现三级列表  
- 路由：`/settings` 根；`/settings/appearance|glass|motion|reading|storage|about`  
- 子页顶栏：返回 + 标题；底栏可扩展胶囊 **保留**（壳层一致）  
- 行组件统一：`SettingRow`（icon + 标题 + 摘要 + chevron）进 chromeGlass 卡；页内直接控件用分段/滑杆  
- 阅读页菜单 = **会话级**快捷项；设置里阅读默认值 = **全局**；冲突时菜单当场改写并回写全局  

```
设置（根）
├── 外观          appearance
│   主题色 / 明暗 / 动态取色 / 书架布局 / 状态栏
├── 材质与玻璃    glass
│   液态|毛玻璃 / 底栏模糊 / 色渗 / 菜单模糊 / 减弱动态时降级说明
├── 动效          motion
│   转场时长档 / 书架重排 / Hero / 翻页默认模式与速度 / 系统「减弱动态」尊重
├── 阅读默认      reading
│   字体·字号·行距·边距 / 段落 / 翻页 / 夜间纸色 / 进度记忆策略
├── 存储          storage
│   封面缓存占用·清理 / 热分页缓存 / 解析会话 / 仅 Wi-Fi 预热
└── 关于          about
    版本 / 开源许可 / 隐私
```

子页控件：模式/枚举 → `LiquidGlassSegmented`；连续值 → `LiquidGlassSlider`（height 56）；布尔 → 玻璃 Switch 或分段；破坏性（清缓存）→ 底部独立 danger 行，不进胶囊主操作。

**与阅读菜单分工**

| 项 | 阅读菜单 sheet | 设置「阅读默认」 |
|----|----------------|------------------|
| 本章进度 | 是 | 否 |
| 翻页模式/速度 | 是（改全局默认） | 是（同字段） |
| 字号/行距/边距 | 是（快捷） | 是（全量+字体文件） |
| 段落/标点压缩 | 否 | 是 |
| 纸色/夜间 | 一键切换 | 调色板与默认 |

### 阅读菜单 IA（attached sheet）

```
┌─ grabber ─────────────────────────────┐
│ 章标题 ···················  [夜间] [×] │
│ ●────────进度────────○   p.12/86     │
│ [上一章] [目录] [下一章]              │
│ 翻页: (仿真|平滑|无)  速度: (快|中|慢)│
│ 字体·字号·边距 ·····················  │
└───────────────────────────────────────┘
```

- 形态：贴底满宽，上圆角 28，底部 safe area 内嵌；背后阅读页 **不** 再叠一层模糊板（sheet 自身 Lens 采样正文即可）  
- 进度：`LiquidGlassSlider`，轨道 chrome 色，thumb 液态  
- 分段：翻页模式/速度用 `LiquidGlassSegmented`  
- 章导航：三枚 `LiquidGlassTabBarAction` 圆键 + 中间「目录」  
- 动效：上滑 280ms easeOutCubic；关闭同曲线反向；尊重 disableAnimations  

### 阅读顶栏

- 保持「封面 dominant 雾 + 渐变消失」，**不用** Lens（避免双 capture）  
- 操作键：返回常显；其余随菜单
