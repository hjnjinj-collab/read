# Bug 修复报告：M9 字体架构重写——不指定字体，用户可选

## 修复日期
2026-08-29

## 问题概述

APK 跑通后，点击进入阅读页**字体显示"不存在"**——所有文本无法显示。根因是：
- `ReaderFont.candidatePaths` 写死 5 个 **Windows-only 路径**（`C:/Windows/Fonts/*.ttc`）
- Android 上一个都对不上 → `loadFontFile` 全部失败
- `_loadSystemFont` 静默吃完异常，函数返回后 `ReaderFont.family` 还是 `'sans-serif'`
- 实际渲染用平台默认字体（Roboto/Noto Sans），但**用户看到的是空白/字体缺失**——因为 M7 字体统一约束破，Rust 测量用不存在的 `'default'` 字体 → `Err("字体不存在: default")` 冒泡到 Dart

**用户诉求（已确认）**：
> "为了适配之后的字体多样性选择，应该不指定字体才对"
> "我希望的是之后用户可以自己选择想要应用的字体，无论是 Windows 端还是移动端都需要"

**关联决策**（2026-08-29 用户确认）：
- 内置 Noto Sans CJK SC subset（7.95 MB）作默认字体
- 字体来源仅 file_picker（不预置多款）
- FRB codegen 必须重启（添加 set_default_font / get_default_font_name FFI 入口）

## 根本原因

### 1. 候选表硬编码

`lib/core/services/reader_font.dart:17-23` 5 个 Windows 路径，移动端 0% 命中：

```dart
static const List<String> candidatePaths = [
  'C:/Windows/Fonts/simsun.ttc',
  'C:/Windows/Fonts/msyh.ttc',
  'C:/Windows/Fonts/simhei.ttf',
  'C:/Windows/Fonts/simkai.ttf',
  'C:/Windows/Fonts/arial.ttf',
];
```

### 2. FontManager 找不到字体直接抛错

`rust/crates/layout_engine/src/font_manager.rs:55-58`：

```rust
pub fn get_font(&self, name: &str) -> Result<&FontRef<'static>> {
    self.fonts.get(name)
        .ok_or_else(|| anyhow!("字体不存在: {}", name))
}
```

`'default'` 不在 `self.fonts` 里 → 抛 Err → `getPageProcessed` 整体失败 → ReaderProvider 拿不到 PageInfo → UI 显示空。

### 3. 字体"写死"语义

- `book_service.dart:122,154,188,226,...` 共 8 处 `String fontName = 'default'`
- `main.dart:32` 调 `loadFontFile("default", path)` 写死 `default` 这个名字
- 任何想换字体的行为都得改源码字面量

## 解决方案

### 新字体架构（4 个核心组件）

```
[启动]  BookService.init()
          → FONT_MANAGER 懒加载
          → FontManager::new_with_embedded_default()
            → include_bytes!("../../../assets/NotoSansSC-Regular.otf")
            → 解析为 ab_glyph::FontRef
            → 注册名 "embedded_default"，设为 default_font

       ReaderFont.initialize()        [Dart 端]
          → rootBundle.load("assets/fonts/NotoSansSC-Regular.otf")
          → FontLoader("ReaderSerif").addFont(...)
          → family = "ReaderSerif"
          → displayName = "内置 Noto Sans CJK SC"

       两侧同源 ✅ 满足 M7 测量/绘制同源约束

[用户切换]  FontProvider.pickAndLoadCustomFont(context)
             → FilePicker.pickFiles(.ttf/.otf/.ttc)
             → 读 bytes
             → ReaderFont.loadCustomFont(name, bytes, displayLabel)
               → loadFontData(name, bytes)        [Rust 注入]
               → setDefaultFont(name)             [Rust 切换]
               → FontLoader(name).addFont(...)    [Dart 注入]
               → family = name                   [Dart 切换]
```

- 协议：SIL Open Font License 1.1

### 2. Rust 端 `font_manager.rs` 改造

```rust
const EMBEDDED_NOTO_SANS_SC: &[u8] =
    include_bytes!("../../../assets/NotoSansSC-Regular.otf");
pub const EMBEDDED_DEFAULT_FONT_NAME: &str = "embedded_default";

impl FontManager {
    pub fn new_with_embedded_default() -> Self {
        let mut mgr = Self::new();
        mgr.load_embedded_default().expect("内置字体 build 时嵌入，不应失败");
        mgr
    }

    pub fn load_embedded_default(&mut self) -> Result<()> {
        self.load_font(EMBEDDED_DEFAULT_FONT_NAME.to_string(),
                       EMBEDDED_NOTO_SANS_SC.to_vec())?;
        self.default_font = Some(EMBEDDED_DEFAULT_FONT_NAME.to_string());
        Ok(())
    }

    /// 三级 fallback：name → default_font → 任意已加载 → 抛错
    pub fn get_font(&self, name: &str) -> Result<&FontRef<'static>> {
        if let Some(f) = self.fonts.get(name) { return Ok(f); }
        if let Some(d) = self.default_font.as_ref() {
            if let Some(f) = self.fonts.get(d) { return Ok(f); }
        }
        if let Some((_, f)) = self.fonts.iter().next() { return Ok(f); }
        Err(anyhow!("字体管理器为空"))
    }

    pub fn set_default_font(&mut self, name: &str) -> Result<()> {
        if !self.fonts.contains_key(name) {
            return Err(anyhow!("未加载此字体：{}（先 load_font）", name));
        }
        self.default_font = Some(name.to_string());
        Ok(())
    }
}
```

### 3. Rust 端 `api.rs` 改造

`FONT_MANAGER` 改用 `new_with_embedded_default()`：

```rust
static FONT_MANAGER: Lazy<Arc<Mutex<FontManager>>> = Lazy::new(|| {
    Arc::new(Mutex::new(FontManager::new_with_embedded_default()))
});
```

`load_font_file` 软失败（不再抛错）：

```rust
pub fn load_font_file(font_name: String, font_path: String) -> anyhow::Result<()> {
    let mut manager = FONT_MANAGER.lock().unwrap();
    match manager.load_font_from_file(font_name, &font_path) {
        Ok(()) => {
            SHARED_GLYPH_CACHE.lock().unwrap().clear();
            Ok(())
        }
        Err(e) => {
            log::warn!("load_font_file failed ({}): {}", font_path, e);
            Ok(())  // 软失败：FontManager 已有 embedded_default 兜底
        }
    }
}
```

新增 FFI 入口（FRB codegen 后暴露给 Dart）：

### 6. Dart 端 `font_provider.dart` 新增

```dart
class FontProvider {
  static Future<bool> pickAndLoadCustomFont(BuildContext context) async {
    final result = await FilePicker.pickFiles(
      type: FileType.custom,
      allowedExtensions: ['ttf', 'otf', 'ttc'],
    );
    if (result.isEmpty) return false;
    final picked = result.first;
    if (picked.path == null) return false;
    final bytes = await File(picked.path!).readAsBytes();
    // 用文件名 stem + FNV-1a 短 hash 拼字体族名（避免同名冲突 + 不暴露路径）
    final fontName = 'user_${stem}_${shortHash}';
    return await ReaderFont.loadCustomFont(
      name: fontName, bytes: bytes, displayLabel: '用户字体：$stem',
    );
  }
}
```

## M7 同源约束的处理

| 状态 | Rust 测量 | Dart 绘制 | 同源？ |
|---|---|---|---|
| 启动默认 | `embedded_default` (Noto Sans CJK SC) | `ReaderSerif` (Noto Sans CJK SC，同一字节) | ✅ |
| 用户切字体 | 用户注入的 name + bytes | 用户注入的 name + bytes（同 family） | ✅ |
| Rust 字体没找到 | fallback 到 default（embedded_default） | n/a | n/a |
| Dart 字体没找到 | n/a | Flutter 静默回退默认 | n/a |

**关键**：`family` 字段在 Rust 端（`LayoutConfig.font_name`）和 Dart 端（`TextStyle.fontFamily`）**始终同步**——通过 `ReaderFont.family` 这个共享变量维持。

## 预防/工程约束

**字体架构的硬约束（新增 M9 约束）**：
1. **不写死具体字体名**——所有 FFI 入口的 `font_name` 参数可以是任意字符串；FontManager 三级 fallback 保证鲁棒性
2. **不写死候选路径**——内置默认 + 用户显式选双通道，不靠"系统扫"碰运气
3. **双引擎同源**——测量端和绘制端必须用**同一字体族名**（Rust FontManager + Dart FontLoader 同步注册）
4. **加载失败不抛**——`loadFontFile` 软失败，因为 FontManager 已有内置默认兜底
5. **切换字体清缓存**——`loadFontData` / `setDefaultFont` 都要 `SHARED_GLYPH_CACHE.clear()`，防旧字形混入

**未来扩展**：
- 字体持久化（用户选的字体路径存进 shared_preferences / drift，重启自动恢复）
