# 章节标题重复问题修复报告

## 问题描述

### 问题1：重复标题未被删除 ✅ 已修复

**现象**：
- 测试文件 `贷款武圣(1-280章).txt` 每章开头都有重复的标题
- 第一行：`第3章 披挂刀法！`（无缩进）

## 根本原因分析

### 章节内容提取流程

1. **章节识别** (`ChapterExtractor.build_chapter_info()`)
   - JS 引擎识别章节标题行（返回 `line_number`）
   - 计算章节内容的 `start_offset`：指向**标题行的下一行**
   - 例如：第144行是标题 → `start_offset` 指向第145行

2. **内容净化缓存** (`TxtParser.build_cleaned_chapter_cache()`)
   - 全文净化 → 构建行号映射
   - 计算每章的净化后偏移：`start_pos = mapper.map_line_to_offset(line_number + 1)`
   - 从缓存读取章节内容

3. **内容预处理** (`ContentPreprocessor.process()`)
   - 删除重复标题 (`remove_duplicate_title()`)
   - 重新分段、繁简转换等

### 问题根源

**文件实际结构**：
```
第144行：第3章 披挂刀法！         （无缩进，JS 识别到这一行）
第145行：　　第3章 披挂刀法！     （带缩进，重复标题）
第146行：　　赵大、赵二兄弟是谁？ （正文）
```

**章节内容起始位置**：
- `start_offset` 指向第145行（标题行 + 1）
- 所以章节内容开头就是带缩进的重复标题

**旧的 `remove_duplicate_title()` 失败原因**：
```rust
// 旧逻辑
content_trimmed.starts_with(trimmed_title)
// trimmed_title = "第3章 披挂刀法！"
// content_trimmed = "　　第3章 披挂刀法！..."（带全角空格缩进）
// 无法匹配！
```

## 解决方案

### 修复1：优化 `remove_duplicate_title()` ✅ 已完成

**位置**：`rust/crates/reader_core/src/content_preprocessor.rs:200`

**新逻辑**：
1. 逐行扫描内容开头的每一行
2. 对每一行去除前后空白（包括全角空格 `\u{3000}`）后与标题比较
3. 如果匹配，删除该行及其前面的所有空行
4. 支持多次重复的标题（如：标题连续出现2次）

**关键代码**：
```rust
fn remove_duplicate_title(content: &str, title: &str) -> String {
    let trimmed_title = title.trim();
    if trimmed_title.is_empty() {
        return content.to_string();
    }

    let lines: Vec<&str> = content.lines().collect();
    let mut skip_until_line = 0;
    
    // 逐行扫描，查找所有重复的标题行
    for (i, line) in lines.iter().enumerate() {
        // 去除行首尾的空白字符（包括全角空格 \u{3000}）
        let line_trimmed = line.trim_start_matches(|c: char| {
            c.is_whitespace() || c == '\u{3000}'
        }).trim_end();
        
        if line_trimmed == trimmed_title {
            // 找到匹配的标题行，标记跳过到此行（包含此行）
            skip_until_line = i + 1;
        } else if !line_trimmed.is_empty() {
            // 遇到非空的非标题行，停止扫描
            break;
        }
    }
    
    if skip_until_line > 0 {
        // 跳过所有标题行及其前面的空行，返回剩余内容
        let remaining_lines = &lines[skip_until_line..];
        remaining_lines.join("\n")
    } else {
        content.to_string()
    }
}
```

### 修复2：章节分页 ⏳ 待实现

**需求**：
- 新章节应该强制另起一页
- 即使上一页还有空间，也不应该在上一页末尾显示新章节的开头

**实现方案**：

**方案A：在 TextLine 中添加章节边界标记**
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TextLine {
    pub text: String,
    pub x: f32,
    pub y: f32,
    pub width: f32,
    pub height: f32,
    pub is_chapter_start: bool,  // 新增：标记是否是章节开头
}
```

**方案B：在分页时传递章节边界信息**
```rust
pub fn paginate(
    &self,
    lines: &[TextLine],
    page_height: f32,
    chapter_index: usize,
    chapter_boundaries: &[usize],  // 新增：章节边界行号列表
) -> Vec<Page>
```

**推荐方案**：方案A更简单，直接在 `TextLine` 中标记章节开头，分页器检测到 `is_chapter_start = true` 时强制分页。
