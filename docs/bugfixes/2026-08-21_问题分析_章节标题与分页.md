# 问题分析：章节标题重复和内容拼接

## 用户反馈的问题

1. **章节内容中重复显示标题**
2. **左右翻页时，一页章节结束后紧接着显示下一章内容**（应该分章显示）

## 可能的原因

### 原因1：章节起始位置包含标题

当前 `extract_chapters_mmap()` 和 `extract_chapters_static()` 中：
```rust
chapters.push(RawChapter {
    title: trimmed.to_string(),
    start_pos: line_start,  // 指向标题行的起始 ❌
    end_pos: 0,
});
```

这导致章节内容**包含了标题行**。

### 原因2：分页逻辑问题

Flutter 侧的分页器可能没有正确处理章节边界，导致：
- 一页显示完当前章节后
- 直接继续显示下一章节的内容
- 而不是在新的一页开始新章节

### 原因3：章节内容提取逻辑

在 `get_chapter_content_from_cache()` 中返回的内容包含了标题。

## 解决方案

### 方案1：修改章节起始位置（推荐）

**位置**: `extract_chapters_mmap()` 和 `extract_chapters_static()`

**修改**: 将 `start_pos` 设置为标题行的**下一行**起始，而不是标题行起始

```rust
// 当前（错误）
chapters.push(RawChapter {
    title: trimmed.to_string(),
    start_pos: line_start,  // 包含标题
    end_pos: 0,
});

// 修改后（正确）
let content_start = line_start + line.len() + 1;  // 跳过标题行和换行符
chapters.push(RawChapter {
    title: trimmed.to_string(),
    start_pos: content_start,  // 从标题后开始
    end_pos: 0,
});
```

### 方案2：在返回内容时去除标题

**位置**: `get_chapter_content_from_cache()` 或 `get_chapter_content_internal()`

**修改**: 返回内容前，去除第一行（标题行）

```rust
pub fn get_chapter_content_from_cache(&self, chapter_index: usize) -> Result<String> {
    // ... 获取内容
    let mut content = cleaned_content[start..end].to_string();
    
    // 去除第一行（标题）
    if let Some(first_newline) = content.find('\n') {
        content = content[first_newline + 1..].to_string();
    }
    
    Ok(content)
}
```

### 方案3：Flutter 侧分页处理

**位置**: Flutter 的分页器

**修改**: 在章节边界处强制分页，不要跨章节显示内容

```dart
// 伪代码
if (currentPageEndPosition >= currentChapterEndPosition) {
  // 当前页结束在章节边界
  // 下一页应该从下一章节开始
  nextPageChapterIndex = currentChapterIndex + 1;
  nextPageStartPosition = 0;  // 从新章节的开头开始
}
```

## 推荐的修复步骤

### Step 1: 修复章节起始位置（最直接）

修改 `extract_chapters_mmap()` 和 `extract_chapters_static()` 中的章节记录逻辑，让 `start_pos` 指向标题的**下一行**。

这样：
- `chapter.start_pos` ~ `chapter.end_pos` 之间的内容**不包含标题**
- `build_cleaned_chapter_cache()` 中的 `line_number + 1` 逻辑也是正确的

### Step 2: 验证分页逻辑

确保 Flutter 侧的分页器在章节边界处正确处理：
- 一个章节结束后，下一页应该从**新章节**开始
- 不要将多个章节的内容拼接在同一页

### Step 3: 测试

```dart
// 测试1：检查章节内容是否包含标题
final content = await api.getChapterContent(bookId, 0);
assert(!content.startsWith(chapterTitle));  // 不应该以标题开头

// 测试2：检查章节边界
final chapter1 = await api.getChapterContent(bookId, 0);
final chapter2 = await api.getChapterContent(bookId, 1);
assert(!chapter1.contains(chapter2Title));  // 第1章不应包含第2章标题
```
