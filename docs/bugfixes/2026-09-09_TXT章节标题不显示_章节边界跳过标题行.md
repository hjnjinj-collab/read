# TXT 章节标题不显示 — 章节边界计算跳过标题行

> 日期：2026-09-09
> 症状：TXT 格式书籍章节标题不显示在正文开头，正文直接从标题后的第一行开始
> 影响范围：所有 TXT 格式书籍
> 严重程度：高（核心阅读体验）

---

## 一、问题描述

用户报告 TXT 格式书籍的章节标题不显示在正文开头。截图显示正文直接从"夜色如墨..."开始，没有章节标题行。

## 二、根因分析

### 2.1 问题链条

项目默认启用 `js-engine` feature（`Cargo.toml` L25: `default = ["js-engine"]`），TXT 章节边界计算走 JS 引擎路径：

```
build_cleaned_chapter_cache
  ↓
compute_cleaned_offsets
  ↓
#[cfg(feature = "js-engine")]
ChapterExtractor::extract_chapters(cleaned_content)
  ↓
build_chapter_info(content, js_chapters)
  ↓
start_offset = line_start(js_chapter.line_number + 1)  ← BUG: 跳过标题行
```

### 2.2 根因代码

**文件**：`rust/crates/book_parser/src/chapter_extractor.rs` L216-217

```rust
// 章节内容的起始位置：标题行的下一行行首（不含标题）
let start_offset = line_start(js_chapter.line_number + 1);  // ← BUG
```

**`line_number + 1`** 表示从标题行的**下一行**开始，**显式排除了标题行**！

### 2.3 同源缺陷

**文件**：`rust/crates/book_parser/src/txt_parser.rs` L372-373（非 JS 回退路径）

```rust
// 章节起始：标题行之后；结束：下一章标题行之前
let start_pos = mapper.map_line_to_offset(tl + 1);  // ← 同样的 BUG
```

### 2.4 为什么 `remove_duplicate_title` 无效

用户已关闭 `remove_duplicate_title` 功能（`enabled=false`），但标题**从一开始就不在章节内容中**，所以无论去重功能开启还是关闭，标题都不会显示。

### 2.5 诊断过程

1. **第一次尝试**（commit aba63cd）：修改 `remove_duplicate_title` 函数逻辑，保留第一个标题
   - 结果：无效（问题不在去重逻辑）

2. **第二次尝试**（commit 850d4ff）：修改 `align_offsets_by_title` 的 `tl + 1` → `tl`
   - 结果：无效（代码走的是 JS 引擎路径，不是 `align_offsets_by_title`）

3. **第三次尝试**（commit ef43acf）：修改 `build_chapter_info` 的 `line_number + 1` → `line_number`
   - 结果：有效 ✅

## 三、修复方案

### 3.1 JS 引擎路径（主要修复）

**文件**：`rust/crates/book_parser/src/chapter_extractor.rs` L216-217

```rust
// 修改前：
let start_offset = line_start(js_chapter.line_number + 1);

// 修改后：
let start_offset = line_start(js_chapter.line_number);
```

### 3.2 Rust 回退路径（同步修复）

**文件**：`rust/crates/book_parser/src/txt_parser.rs` L372-373

```rust
// 修改前：
let start_pos = mapper.map_line_to_offset(tl + 1);

// 修改后：
let start_pos = mapper.map_line_to_offset(tl);
```

### 3.3 `remove_duplicate_title` 逻辑优化（附带修复）

**文件**：`rust/crates/reader_core/src/content_preprocessor.rs` L268-323

旧逻辑删除**所有**匹配的标题行（包括第一个），新逻辑保留第一个标题，只删除后续重复的。

## 四、验证结果

- book_parser: 123 ✅
- reader_core: 146 ✅
- bridge: 17 ✅
- 真机验证：标题正确显示 ✅

## 五、教训

1. **Feature flag 隐藏代码路径**：`js-engine` 默认开启，但诊断时容易忽略 JS 路径，只关注 Rust 回退路径
2. **同源缺陷多路径存在**：`line_number + 1`（JS 路径）和 `tl + 1`（Rust 路径）是同样的逻辑错误，修复时需要同时检查所有路径
3. **日志诊断的有效性**：`eprintln!` 强制日志帮助确认了 `remove_duplicate_title` 根本没有被调用，排除了去重逻辑的嫌疑
4. **缓存影响**：修改章节边界计算后，需要重新打开书籍（触发缓存重建）才能看到效果
